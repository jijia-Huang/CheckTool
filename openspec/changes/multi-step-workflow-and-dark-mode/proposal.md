## Why
目前的 UI 介面採取垂直排列，隨著資料量增加，頁面會變得過長且難以閱讀。為了提升使用者體驗，需要將作業流程切分為明確的三個步驟：輸入規格、選擇目錄、執行比對。同時，為了因應不同使用場景，需要更完整的深色模式支援。

## What Changes
- **實作多步驟引導 (Wizard Workflow)**：
  - **步驟 1：輸入規格列表** - 專注於 Excel 或文字貼上。
  - **步驟 2：選擇美術資產目錄** - 專注於資料夾選擇與掃描。
  - **步驟 3：執行比對與結果顯示** - 執行最終比對並查看結果。
- **新增步驟導覽列**：在頁面頂部顯示目前的進度。
- **完善深色模式 (Dark Mode)**：
  - 優化 CSS 變數，確保在切換系統深色模式時，所有元件（包括捲軸、邊框、背景）都能正確轉換。
  - 修正特定元件在深色模式下的文字對比度。
- **流程控制**：
  - 新增「下一步」與「上一步」按鈕。
  - 實作步驟校驗（例如：未輸入規格前不能進入下一步）。

## Impact
- **修改程式碼**: 
  - `src/App.tsx` - 改為狀態驅動的多步驟渲染邏輯。
  - `src/App.css`, `src/index.css` - 新增步驟導覽列樣式與完善深色模式 CSS。
  - 各個 Module 元件 - 可能需要微調按鈕佈局以符合步驟導覽風格。
- **使用者體驗**: 流程更清晰，單一頁面資訊負擔減輕。
